Розділ 4 · локально

ШІ на твоєму комп’ютері

Скачуєш модель один раз — і вона працює без інтернету, без лімітів і безкоштовно. Твої дані нікуди не йдуть. Найпростіше — через Ollama.

Скільки в тебе оперативної пам’яті (RAM)?

Як дізнатися RAM: Windows — Ctrl+Shift+Esc → «Продуктивність» → «Пам’ять». Оцінки української — наші, офіційних тестів немає.

1. Встанови Ollama

PowerShell
# або завантаж OllamaSetup.exe з ollama.com/download
$ irm https://ollama.com/install.ps1 | iex

Потрібна Windows 10 (22H2) або новіша, права адміністратора не потрібні.

Завантаж ollama.dmg з ollama.com/download і перетягни в «Програми». Потрібна macOS 14 Sonoma або новіша. На Mac з чипом M працює швидко.

терміналі
$ curl -fsSL https://ollama.com/install.sh | sh

2. Запусти модель і пиши

термінал
# перший запуск скачає модель (~3 ГБ, краще по Wi-Fi)
$ ollama run qwen3.5:4b
# пиши питання прямо тут, вихід — /bye

У Ollama є і звичайний застосунок з вікном чату для Windows і macOS — можна взагалі без терміналу.

Поради, щоб не гальмувало

Бери Q4

Стиснена версія (Q4) удвічі легша за Q8, а якість майже та сама. Ollama за замовчуванням і так дає Q4.

Рахуй пам’ять

Потрібно приблизно: розмір моделі + 1–2 ГБ, плюс ще 2–4 ГБ займає сама система.

Закрий браузер

Вкладки Chrome їдять купу RAM. Закрий зайве перед запуском моделі.

Не роздувай контекст

Довший контекст = більше пам’яті. На 8 ГБ тримай 4–8 тисяч токенів.

Без відеокарти — повільніше

Маленькі моделі (1–4B) на процесорі пишуть нормально, 7–9B — помітно повільніше, 20B+ — боляче.

Звільняй диск

ollama rm назва видаляє модель, ollama stop назва звільняє пам’ять.

Правила гри

Нічого особистого

Не вводь адресу, телефон, паролі, фото документів і чужі дані. Чати можуть читати люди й використовувати для навчання моделей.

Перевіряй факти

Дати, цифри, цитати й посилання звіряй з надійними джерелами. ШІ помиляється впевнено.

Чесно

Не видавай текст ШІ за свій. Використовуй ШІ, щоб зрозуміти, а не щоб списати.

Вимкни навчання на чатах

У налаштуваннях ChatGPT, Perplexity, Grok, Mistral можна заборонити використовувати твої чати для навчання.
