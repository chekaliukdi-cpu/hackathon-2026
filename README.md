# Хакатон 2026 · вайбкодинг з ШІ

Сайт хакатону для учнів 8–11 класів: робота з моделями ШІ та 4 задачі.
Статичний сайт (HTML + CSS + JS), без збірки, розгортається на GitHub Pages.

**Сайт:** https://chekaliukdi-cpu.github.io/hackathon-2026/

## Структура

```
index.html          ← Робота з ШІ (головна)
task-1.html         ← Задача 1   (порожня заготовка)
task-2.html         ← Задача 2   (Discord-бот для зустрічей — готова)
task-3.html         ← Задача 3   (порожня заготовка)
task-4.html         ← Задача 4   (порожня заготовка)
components.html     ← усі готові блоки з кодом для копіювання
404.html
assets/
  css/style.css     ← спільні стилі (тема, навігація, компоненти)
  css/task2.css     ← стилі тільки для Задачі 2
  js/main.js        ← навігація, переходи, свайпи, вкладки, анімації появи
  js/task2.js       ← анімації та симуляція Задачі 2
  img/favicon.svg
```

## Як заповнити свою сторінку

1. Відкрий свій файл (`task-1.html`, `task-3.html`…), знайди коментар `>>> ПИШІТЬ КОНТЕНТ ТУТ`.
2. Готові блоки (картки, підказки, термінал, вкладки, FAQ) копіюй з `components.html`.
3. Потрібні власні стилі? Створи `assets/css/task-N.css` і підключи його в `<head>` своєї сторінки.
4. Колір сторінки міняється в `assets/css/style.css` → `body[data-page="task-N"]`.
5. Назву вкладки в меню міняєш у масиві `PAGES` на початку `assets/js/main.js`.

Навігація й футер вставляються автоматично тегами `<site-nav>` і `<site-footer>`, тож редагувати їх у кожному файлі не треба.

## Кеш браузера

До підключених CSS/JS додано `?v=4`. Якщо змінив стилі чи скрипти — збільш число (наприклад, `?v=5`) у всіх `.html`, тоді користувачі одразу отримають нову версію.

## Локальний перегляд

```bash
python -m http.server 8000
# відкрий http://localhost:8000
```

## Публікація

Push у гілку `main` → GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
